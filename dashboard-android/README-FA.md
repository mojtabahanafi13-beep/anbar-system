# اپ اندروید داشبورد روژین

این پروژه جدا از مخزن اندروید سفیر روژین است و هیچ فایل یا کدی از پروژه راننده را تغییر نمی‌دهد.

## روش کار

برنامه یک میانبر نصب‌شدنی اندروید برای داشبورد عملیاتی موجود است و URL اصلی زیر را در Chrome Custom Tab باز می‌کند:

\`https://server.factor-anbar.online/dashboard/dashboard.html\`

عمداً برنامه وب را داخل WebView مستقل بازنویسی نمی‌کند؛ داشبورد فعلی از Service Worker، Web Push، اعلان‌ها، بارگذاری و دانلود فایل، دوربین و قابلیت‌های مرورگر استفاده می‌کند. اجرای آن در موتور مرورگر کمک می‌کند همین قابلیت‌های موجود روی همان مبدأ و با همان APIهای سرور باقی بمانند.

## ساخت APK

Workflow مربوط به GitHub Actions فایل \`Rojin-Dashboard.apk\` را می‌سازد و به‌صورت Artifact با نام \`Rojin-Dashboard-APK\` منتشر می‌کند. این ساخت Debug-signed برای نصب و آزمایش داخلی است، نه نسخه نهایی فروشگاه.

## نصب و استفاده

1. Artifact را از اجرای موفق workflow دانلود کنید و ZIP مربوط به Artifact را استخراج کنید.
2. فایل \`Rojin-Dashboard.apk\` را به گوشی اندروید منتقل و نصب کنید.
3. اجرای برنامه داشبورد را در مرورگر باز می‌کند. در اولین استفاده، ورود و اجازه‌های دوربین/مکان/اعلان را در خود Chrome طبق نیاز سایت تنظیم کنید.
4. برنامه برای کار به اینترنت و سرور عملیاتی نیاز دارد؛ هیچ داده یا پایگاه‌داده‌ای را به APK کپی نمی‌کند.

## ملاحظات

- این APK جایگزین سرور یا APIها نیست و به‌خودی‌خود حالت آفلاین کامل اضافه نمی‌کند.
- اعلان Push به قابلیت‌های مرورگر و مجوزهای سایت وابسته است؛ پس از بازشدن داشبورد، وضعیت اعلان Push را از تنظیمات خود داشبورد بررسی کنید.
- برای انتشار عمومی یا فروشگاه، امضای Release اختصاصی و مدیریت‌شده لازم است.
