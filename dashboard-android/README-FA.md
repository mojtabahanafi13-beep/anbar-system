# اپلیکیشن بومی داشبورد روژین

این پروژه، برنامه اندرویدی مستقل داشبورد است؛ از **Android Views و یک MapView بومی** استفاده می‌کند و برای نمایش رابط کاربری به Chrome، Custom Tabs یا WebView وابسته نیست. پروژه سفیر روژین/پرتال راننده مستقل است و در این تغییرات دست‌نخورده باقی می‌ماند.

## اتصال به سرور

- مبدأ API: \`https://server.factor-anbar.online\`
- ورود و فهرست کاربران داشبورد با شرکت \`rojin-dash\` انجام می‌شود.
- توکن ورود در ذخیره‌ساز خصوصی برنامه نگهداری و در درخواست‌های API با \`Authorization: Bearer\` ارسال می‌شود.
- برنامه به پایگاه‌داده یا فایل‌های داخلی سرور مستقیم دسترسی ندارد.
- برای دریافت اطلاعات واقعی نیاز به شبکه و سرور عملیاتی است.

## ماژول‌های بومی فعلی

1. صفحه ورود بومی.
2. نمای کلی KPIهای سفر (آماده ارسال، در مسیر، تکمیل‌شده و نیازمند رسیدگی).
3. فهرست اسناد خروج/بار و هشدارهای وزن نامشخص.
4. اطلاعات فاکتورها و جست‌وجوی محلی در فهرست دریافت‌شده.
5. ناوگان، وضعیت خودرو/راننده، ظرفیت بار، توقف‌ها، اتصال و آخرین مختصات گزارش‌شده.
6. نمایش نشانگر موقعیت خودروها با MapView بومی مبتنی بر OpenStreetMap.
7. تازه‌سازی مستقیم از APIهای فعلی سرور و خروج امن از نشست محلی.

## مواردی که هنوز برای برابری کامل لازم است

این نسخه یک **فاز اولیه واقعی و بومی** است، نه ادعای تبدیل تمام ابزارهای داشبورد وب. پیش از جایگزینی کامل داشبورد وب، باید صفحه‌ها و عملیات باقی‌مانده به‌صورت بومی نیز پیاده‌سازی و آزمون شوند: برنامه‌ریزی هوشمند و تخصیص/اصلاح ارسال، جزئیات مسیر و توقف‌ها، پیام و صدای راننده، رسید و عکس/امضا، آرشیو و بازیابی، مدیریت کاربران/تنظیمات و عملیات خودکار فاکتور. این نسخه هیچ‌کدام از آن عملیات را با رفتار جعلی شبیه‌سازی نمی‌کند و در بخش‌های نمایش فقط داده‌های سرور را می‌خواند.

## ساخت APK

GitHub Actions از مسیر \`.github/workflows/build-dashboard-apk.yml\` فایل \`Rojin-Dashboard.apk\` را می‌سازد و در Artifact با نام \`Rojin-Dashboard-APK\` می‌گذارد. ساخت Debug-signed فقط برای آزمایش داخلی است؛ برای انتشار عمومی نیاز به امضای Release مدیریت‌شده وجود دارد.
