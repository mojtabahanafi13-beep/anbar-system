# داشبورد انبار و توزیع

این مسیر در GitHub Pages فقط نقش **ورودی** دارد و کاربر را به داشبورد عملیاتی روی سرور منتقل می‌کند:

https://server.factor-anbar.online/dashboard/dashboard.html

این انتقال عمدی است: داشبورد فعلی به APIهای هم‌مبدأ، ورود و سطح دسترسی سرور، پایگاه‌داده محلی، فایل‌های رسید، ناوگان و اعلان‌ها وابسته است؛ میزبانی مستقیم HTML روی GitHub Pages به‌تنهایی این سرویس‌های سمت سرور را فراهم نمی‌کند.

منبع نسخه‌بندی‌شده فایل‌های رابط کاربری در \`dashboard-source/public/dashboard/\` نگهداری می‌شود. فایل داده کسب‌وکار \`data_export.txt\`، پایگاه‌داده و تنظیمات محرمانه هرگز در این مسیر قرار نمی‌گیرند.
